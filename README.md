# 世界神话大全

本仓库是一套世界神话与宗教原典的汉语 EPUB 合集。底本取公有领域文献，或社群已经公开的文本。译文由整理者借助 [Cursor](https://cursor.com/) 从底本独立写成并编排成书，不是各宗教的官方经文，也不是和合本或其他仍有版权的中译的替代本。

English: [README.en.md](README.en.md)

阅读顺序、空号和未完成条目见 [阅读说明.md](阅读说明.md)。新旧号对照见 [NUMBERING.md](NUMBERING.md)。使用限制见 [DISCLAIMER.md](DISCLAIMER.md)。

## 仓库里有什么

目前发布 **195** 种已译完、带封面的 EPUB。文件名是三位编号加书名，例如 `001 埃利都创世记.epub`。编号沿用原目录，未完成的号空着，后面的书没有往前挤。

`附录/000 FGO神话人物总表.epub` 是 Fate/Grand Order 人物与本书的对照表，只作阅读索引，不进入 001 起的主序列。

本库 **不收** 草稿目录 `_work/`，也不收未封或不完整的 EPUB。

## 哪些书不在这里

- **071《摩诃婆罗多》** 仍占用 071，只译到森林篇约第 155 节，十八篇未完，不入库。072《薄伽梵歌》仍是 072。
- **166《帕西法尔》**、**168《亚瑟之死》**、**186《奇兰·巴兰》**、**188《佛罗伦萨抄本》**、**190《瓦罗奇里手稿》**、**191《纳瓦霍创世记》**、**196《希伊阿卡与佩蕾史诗》**、**199《学宫知识》**、**218《皮斯蒂斯·索菲亚》** 中途暂停，保留原号，不入库。196 与已发布的 **197《佩蕾与希伊阿卡》** 不是同一书。
- **180《姆韦特》** 没有合格的公有领域田野本，已取消，不占号。181 仍是 181。
- 中国卷除 **099《山海经》** 外，旧号 100-121、227-228 按计划不做，不占号。099 之后主序列是 **122《古事记》**。

## 编号怎么读

按文件名排序即可按原目录阅读。遇到空号，去 [阅读说明.md](阅读说明.md) 看它是未完占位还是计划内跳过。完整对照表在 [NUMBERING.md](NUMBERING.md)。
