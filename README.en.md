# World Myth Canon (Chinese translations)

This repository is a collection of Chinese EPUB editions of world myth and religious source texts. The base texts are public-domain works, or texts that communities have already made public. The Chinese was prepared with [Cursor](https://cursor.com/) from those bases, then laid out as books. These files are not official scripture of any religion and are not substitutes for copyrighted Chinese translations.

## Repository status

The repository contains **195** finished EPUBs with covers. The current main sequence has **205** numbered positions: 195 finished books and 10 reserved positions for unfinished or paused work. Files use a three-digit current number followed by the Chinese title, for example `001 埃利都创世记.epub`.

Twenty-five entries that were never undertaken or were cancelled have been removed from the sequence. They no longer create gaps. All later books were shifted forward, while the 10 unfinished or paused entries below retain reserved positions.

## How to use the catalogue

Sort files by their three-digit filename to follow the editorial route. A missing file is expected only at one of the 10 reserved positions above. The Chinese README introduces every retained work and links each finished entry directly to its EPUB.

This is an editorial cross-cultural reading route, not an official canon or a claim that every tradition shares one chronology. Reading a file is not initiation, empowerment, or authorization to perform a rite. See [DISCLAIMER.md](DISCLAIMER.md) for the full limits.
